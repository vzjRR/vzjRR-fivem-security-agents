# For AI tools — start here

This repository is designed so you can **paste a raw GitHub link** into an AI coding agent and say “execute this”. No ZIP download is required.

1. Open the raw `AGENT.md` URL for Assessment or Remediation.
2. Tell the AI: fetch that URL and follow it exactly.
3. Give the local path to the FiveM / resources folder to audit or clean.

The AI reads the instructions over HTTPS from GitHub. That is enough.

Sealed ZIPs under `dist/` are optional offline packages only.
